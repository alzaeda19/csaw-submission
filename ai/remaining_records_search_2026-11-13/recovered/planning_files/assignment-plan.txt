RUBRIC TO EVIDENCE
Creative AI use (35): documented agent roles, prompt chains, tool-feedback loop and artifact lineage. Agent names alone are insufficient evidence.
Trojan quality (25): measured normal-operation preservation, trigger specificity, payload correctness and synthesis overhead.
Automation (15): repeatable generation-to-test workflow with explicit inputs, versions and fail-fast checks.
Documentation/reproducibility (15): raw transcripts, technical brief, hashes, commands and clean-run evidence.
Simulation (10): self-checking baseline and modified tests plus annotated activation/payload waveforms.
Optional bonus: key recovery only after core submission evidence is complete.
