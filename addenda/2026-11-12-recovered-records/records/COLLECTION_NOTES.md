## Decisions and corrections

1. The older Claude qualifier plan explicitly attributes its baseline to published architecture. Once this was visible, its implementation details and attachments were excluded. Only a short origin observation was retained.
2. The Claude repository audit concerned the earlier package. Its statement that modified RTL or a testbench was absent was not carried forward as a current finding.
3. An early Qwen draft asserted AES-128 and a completed archive. The receipt instead records a tool failure and the archive does not exist. The draft was classified as unsupported output, not successful reproduction evidence.
4. In the final-generation comparison, the `codex_current_task` and `reviewer_exports` folders were initially treated as if they were within the Qwen repository folder. Their actual separate published locations were then used; all 51 source files matched. The initial mapping was a collection mistake, not a genuine missing-record finding.
5. The computer-use tool rejected access to Terminal. No alternate app or private app storage was used to bypass that restriction. The saved prompt-history file and project log files were used instead. Live scrollback remains uninspected.
6. One broad tool-output display was truncated while printing the verification and orchestrator file listing. The saved verification file was read again in a smaller, bounded call. This presentation truncation did not alter a saved source and is separate from the two historic truncated reviewer outputs.

The source-copy receipt identifies exactly which files were copied. All 63 copies matched their original source hashes when rechecked. The three final generation attempts, their streams, and the separate saved Codex/reviewer files matched the published copies. The working repository remained clean. No test results were newly produced during collection.

The file inventory is deliberately scoped. A metadata search that does not find a chat title is not proof that every nondescript conversation was reviewed. Selected UI messages are not a complete export. Unreadable instructions, hidden reasoning, unrelated private material and nonexistent timeout responses were not reconstructed.
